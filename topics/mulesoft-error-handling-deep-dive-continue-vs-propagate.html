Q2 [DEVELOPER / SENIOR] ⏱️ 1 min read Module L

What is a Try Scope? When do you use it?

⚡ Self-Test Mode Ready
✓ ANSWER

Try Scope provides localized error handling for a specific group of processors within a flow. Errors in

the Try scope are caught there — they don't propagate to the flow's error handler unless you use on-

error-propagate inside the Try scope.

When to use: When you need different error behavior for one specific part of a flow (e.g., retry a

single DB call while letting the rest of the flow succeed). ForEach uses Try scope around each record

to prevent one failure from stopping the loop.

Q4 [DEVELOPER / SENIOR] ⏱️ 1 min read Module L

How do you propagate an error from SAPI to XAPI through PAPI?

⚡ Self-Test Mode Ready
✓ ANSWER

Use on-error-propagate at each layer. The error message (and payload) propagates up the call chain

automatically.

Enterprise Pattern: SAPI catches SAP HTTP error → builds standardized error payload {correlationId,

errorCode, message, layer:"SAPI"} → propagates. PAPI receives error → enriches with PAPI context →

propagates. XAPI receives error → formats final API error response with correct HTTP status code →

returns to caller.

The key: use a consistent error response format at every layer so the XAPI always knows what shape

the error payload will be regardless of which layer it originated from.

What is the standard error response format you use across all Enterprise APIs?

⚡ Self-Test Mode Ready
✓ ANSWER

DataWeave — Standard Error Response

DWL 
%dw 2.0
output application/json
---
{
correlationId: vars.correlationId,
timestamp: (now() >> "America/New_York") as String {format: "yyyy-MM-dd HH:mm:ss"},
status: vars.httpStatus,
errorCode: "SAP_TIMEOUT",
message: "Upstream SAP system unavailable",
details: error.description,
apiName: "billing-inquiry-xapi",
apiVersion: "v2.0.0"
}

This format is enforced by the global-config.xml default error handler. Frontend teams never see raw Java/SAP exceptions — always wrapped in this format. Operations filter Splunk by errorCode. correlationId links to full request trace.
