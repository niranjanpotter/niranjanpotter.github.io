Q1 [DEVELOPER] ⏱️ 1 min read Module K

What is Choice Router? How does it work?

⚡ Self-Test Mode Ready
✓ ANSWER

Choice Router evaluates conditions sequentially and routes the message to the FIRST matching route.

Only one route executes. A default route handles messages that don't match any condition (like else

in if-else).

Choice Router Example

🎯🎯 Interview Pitch - Say It Like This (30 Sec)
"I use Choice Router for content-based routing where deterministic DataWeave expressions evaluate which single execution path to take, always configuring a default route for unhandled exceptions. In contrast, First Successful is ideal for active-passive failover—attempting a primary API route first, and only trying the secondary backup if an error is thrown."
💼💼 Real-Time Project Example

Project: Telecommunications — Multi-Carrier Shipping Rate Dispatcher.

Problem: Hardcoded if-else routing logic led to maintainability nightmares and complete order failure when the primary shipping partner API went down.

What I Did: Implemented a Choice router for package size rules, combined with a First Successful scope attempting primary carrier API first, falling back to secondary carrier.

Result: Reduced shipping dispatch errors by 100% and guaranteed zero order checkout interruptions during partner carrier outages.

Q3 [DEVELOPER] ⏱️ 1 min read Module K

What is Async Scope? When do you use it?

⚡ Self-Test Mode Ready
✓ ANSWER

Async Scope executes its processors in a separate thread without blocking the main flow. The main

flow continues and returns a response immediately. The Async scope runs in the background.

Use cases: Sending email notifications (don't want to wait for email server), publishing audit logs,

non-critical writes. Important: Async scope cannot access or modify the main flow's payload — it

works with a copy. Variables modified inside Async are not visible in the main flow after.

Difference from Anypoint MQ async: Async scope uses the same JVM thread pool — not durable. If

app crashes, in-flight async tasks are lost. Anypoint MQ is durable — messages survive restarts.
